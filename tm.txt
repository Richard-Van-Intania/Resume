PROJECT DESCRIPTION

Taengmo is a self-initiated, two-sided recruitment platform designed to connect job seekers with employers. The product provides separate experiences for candidates and hiring teams, covering candidate profile and résumé management, employer and organization profiles, job publishing, application tracking, saved jobs and candidates, personnel administration, and account authentication.

After creating the original version with Vue.js, I redesigned and rewrote the frontend with React, TypeScript, and Next.js. I also structured the rewritten system as a modular full-stack platform: a unified web application, earlier separate employer and job-seeker applications, a reusable React component library, a shared TypeScript utilities package, and a Rust REST API backed by PostgreSQL and S3-compatible object storage.

PORTFOLIO / LINKEDIN DESCRIPTION

Taengmo is my independent side project for exploring the complete product and engineering lifecycle of a modern recruitment platform. I created the product concept and developed both sides of the marketplace: a candidate experience for building professional profiles and managing job applications, and an employer experience for maintaining organizations, publishing jobs, reviewing applicants, and administering hiring personnel.

The first frontend was built with Vue.js. As the product grew, I rewrote it with React, TypeScript, and Next.js and reorganized the code into reusable modules. The current architecture includes a unified web application, a shared component library, common TypeScript models and reference data, and a Rust/Axum backend connected to PostgreSQL and S3-compatible storage. The rewrite allowed me to improve code reuse, type safety, frontend organization, authentication handling, and separation of candidate and employer domains.

CURRENT PROJECT STATUS / INTERVIEW NOTE

Taengmo is an actively developed side project rather than a claimed production deployment. The codebase contains substantial implemented candidate, employer, authentication, profile, storage, and application-management functionality, while some product areas—such as chat, subscriptions, and advanced search experiences—have routes or user-interface foundations that may still require further backend integration and production hardening.

INTERVIEW TALKING POINT

“I started Taengmo as a Vue.js side project, then rewrote it with React, TypeScript, and Next.js when the application became large enough to benefit from stronger typing and a more modular architecture. I built both the job-seeker and employer sides, extracted reusable UI and utility packages, and developed the backend in Rust with Axum, PostgreSQL, JWT authentication, email verification, and S3-compatible storage. The most valuable part was designing the boundaries between candidates, employers, personnel, jobs, applications, and uploaded documents while keeping the user experiences separate but the shared code reusable.”
