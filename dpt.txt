PORTFOLIO / LINKEDIN DESCRIPTION
DPT Town Square is a cross-platform citizen-services mobile application that I developed independently for Thailand’s Department of Public Works and Town & Country Planning (กรมโยธาธิการและผังเมือง). The application provides a single digital entry point through which citizens can discover DPT services, request construction-material testing, submit and follow public complaints or appeals, search official information, communicate with a chatbot or officer, receive status notifications, and manage their account information.

One of the largest journeys is the material-testing service. Users can choose a testing center, enter delivery and site information, locate or configure test items, specify material samples, attach supporting files, review a digital waybill, submit the request, monitor its status, upload payment evidence, and access request and result documents. The application models the many operational states involved, from initial review and material delivery through payment, testing, analysis, approval, and completion.

The public-feedback module supports general complaints, Damrongdhama Center cases, corruption reports, planning and building appeals, and suggestions. Each flow includes purpose-specific forms, citizen and address data, witnesses, supporting media, document previews, submission, reply history, status badges, and attachment downloads.

I also developed a categorized public-information search engine interface with popular content, filters, search history, document metadata, view tracking, and PDF or HTML previews. The support module combines automated chatbot responses and live-officer conversations, supporting text, files, images, quick replies, carousels, pagination, and recurring message updates.

I implemented the application architecture, mobile UI, state management, navigation, API layer, generated data models, authentication, push notifications, deep links, secure storage, file and media workflows, offline behavior, and native Android/iOS configuration. The interface is optimized for Thai citizens and adapts between phone and tablet layouts.

INTERVIEW SUMMARY
I developed DPT Town Square independently, covering the application architecture, reusable interface, complex citizen-service forms, backend integrations, authentication, notifications, document workflows, and native mobile configuration. The main technical challenge was bringing several very different government services into one consistent application while preserving each service’s business rules and long-running status lifecycle.

I used Riverpod to coordinate shared and asynchronous state across multi-step forms, GoRouter’s stateful shell to preserve the state of the main tabs and manage deeply nested journeys, and Freezed with JSON code generation to model a large set of API responses safely. Credentials are stored securely, and protected routes redirect unauthenticated users through the SSO flow before returning them to the intended destination.

Another challenge was making status changes actionable. I connected Firebase push notifications to local notifications and route-specific deep links so that a user can open the relevant testing request, complaint, appeal, or chat directly. I also implemented connectivity monitoring and clear loading, empty, validation, retry, and failure states throughout the application.
